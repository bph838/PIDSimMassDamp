    About the model

    dr/dt = A·θ − Dmain − b·r, dψ/dt = r with A = 64, b = 2 /s, Dmain = 320 °/s². The tail servo follows the command with a first-order lag and a 1000 °/s slew limit. Physics runs at 0.5 ms (semi-implicit Euler); the controller runs at the loop rate.

    Each run starts settled at the hover equilibrium for the current gains, holds setpoint 0° for a 2 s pre-roll (the last 0.5 s is plotted), then steps at t = 0.
