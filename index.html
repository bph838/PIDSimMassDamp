    About the model

    dr/dt = A·θ − torque − b·r, dψ/dt = r with A = 64, b = 2 /s. Main-rotor torque is 320 °/s² at the 6° hover collective and rises with collective² (induced drag). The tail servo follows the command with a first-order lag and a 1000 °/s slew limit. Physics runs at 0.5 ms (semi-implicit Euler); the controller runs at the loop rate.

    Each run starts settled at the hover equilibrium for the current gains, holds still for a 2 s pre-roll (the last 0.5 s is plotted), then the pilot input starts at t = 0.

    The controller is a port of pidApplyYawMode3 and the yaw precomp from Rotorflight (GPL-3.0). Its output is converted at 24° of tail pitch per unit, the configurator's tail scale.
